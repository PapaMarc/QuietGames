# Attribution Guidelines

If you reuse or adapt material from this repository, please provide attribution in a reasonable and visible manner. A simple format is:

**“Based on work by Marc E. Seinfeld, licensed under CC BY 4.0.”**

When possible, please include:

- My name: **Marc E. Seinfeld**
- A link to the original repository
- A note indicating whether you modified the material

Examples of acceptable attribution:

- In a blog post:  
  _“Instructions adapted from Marc E. Seinfeld’s DIY guide (CC BY 4.0).”_

- In a GitHub repo:  
  _“Original steps by Marc E. Seinfeld — reused under CC BY 4.0.”_

- In a video description:  
  _“Repair walkthrough based on Marc E. Seinfeld’s notes (CC BY 4.0).”_

Attribution does not need to be prominent — just clear, reasonable, and discoverable.
